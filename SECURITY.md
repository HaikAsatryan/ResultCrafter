# Security policy

## Supported versions

| Version | Security fixes |
|---------|----------------|
| 3.x     | Yes            |
| 2.x     | No             |

## Official sources

ResultCrafter ships only as `ResultCrafter.*` packages on nuget.org and as source in
[HaikAsatryan/ResultCrafter](https://github.com/HaikAsatryan/ResultCrafter). There is no ZIP or installer download.
Treat anything else that uses the name as unofficial.

## Report a vulnerability

Please do not open a public issue. Report it privately on GitHub: open the **Security** tab of this repository and
choose **Report a vulnerability**. Include the ResultCrafter version, the .NET version and the smallest code that shows
the problem.
